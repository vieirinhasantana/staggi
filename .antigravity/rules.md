# Rules do Projeto Staggi
- Framework Frontend: Svelte 5 (Sintaxe estrita de Runes: $state, $derived, $props).
- Componentes UI: shadcn-svelte (@next) com Tailwind CSS (Tema Zinc/Dark Mode).
- Conceito de Ergonomia: Atalho global de janela (Frameless), sem dependência obrigatoria de mouse.
- Separação de Lógica: A UI é um cliente fino. Ela nunca executa matemática financeira complexa; consome dados estruturados vindos do backend / MCP.
